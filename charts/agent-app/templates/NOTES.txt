Mirror EVERY cron subscription (cron.on()) with a cronJobs entry. Supply DATABASE_URL in an

{{- if and .Values.ingress.enabled (not .Values.ingress.tls.secretName) }}
Ingress without tls.secretName derives an http:// origin. If TLS terminates at
an external load balancer or default certificate, set env.CHAMVI_PUBLIC_URL to
the HTTPS origin. Do not append basePath: the application adds it once.
{{- end }}
The shutdown guard can read env.CHAMVI_FORCE_EXIT_MS only. A value supplied via
envFrom Secret is invisible to Helm. Keep preStop plus the effective force-exit
timeout strictly below terminationGracePeriodSeconds.
{{- if .Values.sandbox.enabled }}

label it for Pod Security restricted). The chart grants the app's ServiceAccount
pods create/get/list/delete and pods/exec get/create there. Select the Kubernetes
provider in the app: env.CHAMVI_SANDBOX_PROVIDER=kubernetes or sandboxModule({ provider: 'kubernetes' }).

The sandbox egress policy only takes effect with an enforcing CNI.
{{- end }}
{{- end }}
